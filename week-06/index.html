Dark Mode

About

What is Dark Mode?

What is it?

Dark mode is an alternative interface theme that replaces bright backgrounds with darker colors. It is designed to reduce screen glare, improve visual comfort, and provide a different viewing experience across digital products such as apps, websites, and operating systems.

Why is it important?

Dark mode supports user preference and improves usability in low-light environments. It can help reduce eye strain and improves accessibility for users with light sensitivity or certain visual conditions. In addition, on devices with OLED displays, darker interfaces can reduce power consumption and extend battery life.

Real-world use case

Dark mode is widely implemented in modern digital platforms such as YouTube, Instagram, X (Twitter), and operating systems like iOS and Android. The toggle on this page demonstrates how interfaces can switch between light and dark themes to support different viewing conditions.

Process

Implementation Details

Step 01. Create the Theme Structure with CSS Variables

First, I created a color system using CSS variables. The default light mode colors were defined in :root, including background, text, surface, and accent colors. Then I created a body.dark rule where the same variables were redefined for dark mode. This allows the entire interface to switch themes simply by adding or removing the dark class.

Step 02. Build the Theme Toggle Interface

Next, I created the theme toggle button using HTML and styled it with CSS. The button allows users to switch between light and dark mode, while the toggle circle visually indicates the current theme state.

Step 03. Implement Theme Switching with JavaScript

Then, I added JavaScript to make the toggle interactive. When the button is clicked, classList.toggle("dark") adds or removes the dark class on the body. This updates the CSS variable values and switches the entire page between light and dark themes.

Step 04. Detect the User’s System Theme Preference

Finally, I used prefers-color-scheme to detect the user’s system setting. If the operating system is already set to dark mode, a small script adds the dark class when the page loads, so the website starts in dark mode automatically.
